# MotoHub — чат, личка и профили участников

В этой версии добавлено:

- отдельное окно чата;
- общий клубный чат;
- личные сообщения 1-на-1 в реальном времени;
- никнейм и фото профиля;
- профиль участника;
- мотоцикл, город, описание;
- история участия в мероприятиях;
- места (1/2/3 и любые другие);
- награды и комментарии;
- все результаты ведёт администратор/модератор через админку;
- статистика по результатам;
- аватар хранится локально в `static/uploads`;
- сохранены email OTP и текущая админка.

## Запуск

1. Распакуйте ZIP.
2. Запустите `START.bat`.
3. Откройте сайт.
4. Войдите по email.
5. Для назначения администратора:
   `.venv\Scripts\python.exe make_admin.py your@email.com`
6. Перезапустите `START.bat`.
7. В админке создавайте события и заносите результаты участников.

## Профиль

Пользователь может сам задать никнейм, фото, город, мотоцикл и описание.

Администратор/модератор может изменить эти данные и добавлять результаты:
- участник;
- мероприятие;
- занятое место;
- награда;
- комментарий.

Профиль доступен по `/profile`, а чужой профиль — `/profile/ID`.

## Важно

В ZIP не записываются пароли Gmail или другие секреты. Для настоящей отправки OTP через Gmail заполните `.env` своими SMTP-данными.
