# MotoHub

MotoHub — мото-сообщество Республики Саха (Якутия): мероприятия, новости, общение, участники, достижения и мото-жизнь региона.

## Что обновлено
- новая красная кинематографичная заставка с движением и мотоциклом;
- заставка показывается один раз за сессию вкладки, а не при каждом F5;
- главная страница разделяет актуальные и прошедшие мероприятия автоматически по дате;
- свежие новости и ближайшее мероприятие выводятся в hero-блоке;
- архив прошедших мероприятий и новостей;
- новости и мероприятия можно создавать, редактировать и удалять;
- фотографии можно добавлять к новостям и мероприятиям;
- админка Control Center: список только ID + никнейм, подробная карточка открывается по клику;
- роли, профиль, достижения, статистика, доверенные устройства и история наказаний в карточке участника;
- предупреждение, мут, временная и постоянная блокировка, снятие ограничений;
- автоматическое завершение временных ограничений без удаления истории;
- уведомления пользователя о наказании и снятии ограничений;
- настройки цветовой схемы и запрос разрешения на браузерные уведомления;
- PWA manifest, service worker и предложение установки на главный экран;
- миграции SQLite без пересоздания пользовательских данных.

## Данные
Обновление приложения не удаляет аккаунты, чат, достижения, историю наказаний, новости и мероприятия. Схема базы расширяется миграциями.

Перед обновлением рекомендуется сделать копию `motohub.db` через `BACKUP_DB.bat`.

## Запуск Windows
Запусти `START.bat`. Для остановки — `STOP.bat`.

Для Gmail OTP скопируй `.env.example` в `.env` и укажи свои SMTP-данные. Секреты в ZIP не включаются.
